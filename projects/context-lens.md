# Context Lens: Making LLM Context Visible

**Human-Computer Interaction project, Toronto Metropolitan University**

## What it is
Chat assistants mix chat history, files, web results and saved memory into every answer, but users rarely see what was used. Context Lens is a redesign concept that lets users see and control what goes into each answer.
